Preparar laboratório Windows

Somente dados fictícios. Esta preparação cria um PostgreSQL privado neste usuário Windows. Não instala serviços nem altera o Sistema Ruy da porta 8080.

Dependência: PostgreSQL 17 x64 de origem confiável, com initdb, pg_ctl, pg_dump e pg_restore. O runtime Electron/Node já está no aplicativo.

C:\Program Files\PostgreSQL\17\bin

Diretório já existente ou preparação interrompida será preservado. Não copie credenciais de outro computador. Nenhuma sincronização com Supabase será ativada.
